Code is authoritative for implemented behavior. Update the architecture guide
alongside changes to owners, wire contracts, persistence, resource limits or
lifecycle. Keep dated observations separate from current behavior; automated
checks and cable probes do not establish receiving-app/listener acceptance.

The screenshots retain their versioned filenames and show earlier desktop/phone
layouts where the interface is still representative. They are illustrations,
not v0.7.0 hardware acceptance evidence.
